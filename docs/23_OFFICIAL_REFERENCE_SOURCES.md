## Reference-use rules

- Use primary sources for capability, pricing, security, and API claims.
- Record access date.
- Prefer stable tagged releases over the main branch.
- Treat Developer Preview/Beta features as unstable and build a fallback boundary.
- Do not copy example scopes without checking the OAuth consent screen and actual tool inventory.
- Treat community tutorials as implementation hints, not authority.
