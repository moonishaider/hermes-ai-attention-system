## Phone messaging remains intentionally unconfigured

Hermes 0.20 exposes WhatsApp and BlueBubbles setup screens, but neither has been enabled. The bundled WhatsApp QR bridge is an unofficial personal-account path with session credentials and account-stability risk; it is not appropriate for Syed's primary WhatsApp. The official WhatsApp Cloud path is more stable but requires a dedicated business number, Meta setup, and a public HTTPS webhook. BlueBubbles is the more practical personal-phone option only if Syed accepts an always-on Mac, a local BlueBubbles server with access to Messages, and a tightly locked allowlist. That persistent gateway is a material lifecycle/security decision and requires its own explicit milestone; it was not smuggled into these first-use fixes.
