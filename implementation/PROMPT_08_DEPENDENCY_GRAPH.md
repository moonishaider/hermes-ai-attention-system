## Non-negotiable cross-cutting dependencies

- Provenance, citations, context isolation, model routing, budget controls, memory, DLOA, and Action Firewall survive every UI change.
- Personal actions require the exact personal account/target and explicit owner request. Work Google, Gmail send, Slack/company/client writes, and generic computer control stay absent.
- Hermes remains the backend and canonical session source. React state may cache presentation data but may not become a second independent memory system.
- Installed-app evidence is required before a ledger item can become `Visible pass`.
- Storage cleanup is last and may target only measured, redundant Jarvis/project artifacts with a retained rollback.
