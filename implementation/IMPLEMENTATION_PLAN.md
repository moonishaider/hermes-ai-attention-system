# Implementation Plan

## Milestone 0 — Safe foundation and compatibility

- Establish Git baseline and implementation records.
- Verify official current capabilities and select a pinned, lightweight implementation stack.
- Define schemas, configuration, policy, audit, and testing foundations.

## Milestone 1 — Intelligence core

- Implement immutable provenance, flexible contexts, evidence, memory proposals, tasks/open loops, audit, and usage controls.
- Implement a deterministic context/policy router and staged action policy.
- Implement registry-driven specialists and adapters.

## Milestone 2 — History and evidence

- Implement read-only Codex history discovery/ingestion.
- Implement ChatGPT export preview/import and explicit context inbox relay.
- Add read-only GitHub contracts and two logical connection configurations.

## Milestone 3 — Attention and experience contracts

- Implement attention ranking, context-switch handoffs, project resumption, uncertainty, commitments, contradictions, and reporting drafts.
- Define the voice/status/overlay event and explicit screen-capture contracts without requesting macOS permissions.

## Milestone 4 — Controlled actions

- Implement proposal hashing, approval expiry, idempotency, destination locks, kill switch, and shadow mode.
- Keep real external executors disabled until supervised manual gates.

## Milestone 5 — Validation and delivery

- Run unit, integration, contract, security, evaluation, secret, migration, and backup/restore tests.
- Finish requirement traceability, limitations, manual runbooks, and rollback records.
- Create and push the private GitHub repository through guarded scripts only.
