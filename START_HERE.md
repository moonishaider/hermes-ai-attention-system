# Start Here — Jarvis

## Open Jarvis

Open **Jarvis** from Applications, Finder, Spotlight, or the Dock. This is the normal product: no Terminal window and no stock Hermes interface are required. Closing the window keeps the menu-bar app available; choose **Quit Jarvis completely** or press **Command+Q** to stop Jarvis and its owned Hermes gateway.

From any Mac app, press **Command+Shift+Space** to open Quick Entry. Type a request and press Return. Open the full app for source progress, Work Ledger, Projects, Missions, Radars, Actions, Learning, and Settings.

## Talk to Jarvis

Click **Talk** or press **Control+Option+Space**, then speak. Click **Stop listening** when finished. Jarvis shows the transcript, acknowledges immediately, and speaks a short natural projection while the complete cited result remains on screen.

- Say **Stop**, or click **Stop speaking**, to interrupt current audio immediately. The narrow spoken-command listener runs only while Jarvis is speaking and stops with the audio.
- Starting Talk while Jarvis is speaking stops that audio before recording.
- If final transcription disagrees materially with the live transcript, Jarvis submits nothing and lets you edit, retry, or discard it.
- If delivery fails, Jarvis retains the transcript in memory and shows **Retry delivery**, **Edit transcript**, and **Discard**.
- Typed chat stays quiet by default.

Wake phrase is intentionally absent/off. The microphone is used only after the visible Talk action or voice shortcut; full Quit leaves no audio process running.

## View one selected screen area

On **Now**, click **Select area**, or use the corresponding one-shot screen control. Drag exactly one region in Apple's visible selector. Jarvis sends that region once to GPT-5.6 Luna, displays the result, discards the pixels, and cannot continuously watch, click, or type.

## Normal daily use

Choose the context before asking: **Inside Success**, **Mitchell · dormant**, **Personal**, **Mixed**, or **Unknown**. Jarvis clears the previous context's visible result when you switch.

Useful first requests:

- `Generate my DLOA for yesterday.` Work dates use Miami time and the output remains an unsent draft.
- `Resume the Jarvis project from my latest Codex and GitHub evidence.`
- `Show my personal obligations for the next seven days, with sources.`

The **Now** page provides Start day, Pre-meeting, End day/DLOA, and Catch up. Multi-source work may take roughly one to three minutes because Jarvis preserves freshness, citations, actor attribution, and context boundaries; it shows what it is checking rather than silently waiting.

## Learning and local capabilities

Say `Remember that I prefer ...` for an explicit low-risk preference. **Learning** shows what Jarvis retained. Capability Studio can create or revise reversible local-only workflows with dry-run and undo; requests requiring code produce a Codex-ready specification and never self-modify or deploy.

## Safety that remains on

Company/client writes, Gmail sending, work Google writes, generic Slack sending, payments, unrestricted browser/computer control, continuous screen capture, and mobile messaging are unavailable. Personal Calendar and Gmail-draft wrappers remain disabled until separately accepted under the project rules. Launch at Login is a visible opt-in and is currently off.

The installed application is `/Applications/Jarvis.app`. Terminal scripts and the stock Hermes UI are diagnostic fallbacks only.
